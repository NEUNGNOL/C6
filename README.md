# C6 🦴

> **코딩할 때 기억하세요. C6 척추뼈는 매일 당신을 지지하고 있습니다.**
>
> 당신의 C6과 함께 스트레칭하며 코딩해보아요!!

## 시작하기

1. `Assets/C6` 폴더를 프로젝트에 넣습니다
2. 상단 메뉴에서 **Tools → C6** 선택
3. 끝. 이제 C6가 같이 일합니다

## C6는 이렇게 지쳐갑니다

15분마다 한 단계씩, 총 4단계.

기본은 15분 간격이지만, 지금 저장소는 **데모용 5초**로 되어 있습니다.
실제로 쓰실 땐 `Assets/C6/Editor/C6Timer.cs`를 열어서 상단의 `kTestMode`를 `false`로 바꿔주세요.

| 단계 | 경과 | 상태 |
|---|---|---|
| 0 | 시작 | 쌩쌩함 |
| 1 | 15분 | 살짝 굳음 |
| 2 | 30분 | 표정 없음 |
| 3 | 45분 | 힘들어함 |
| 4 | 60분 | 뻗음 |

4단계에서 멈춥니다. 시간도 안 흐르고 "C6를 살려주세요—!"만 뜹니다. 저절로 안 낫습니다.

## 살려주기

스트레칭하고 **스트레칭 완료!** 버튼을 누르세요. 바로 0단계로 돌아갑니다.

몇 단계든 언제든 누를 수 있습니다. 미리 누르는 게 좋고요.

단계는 초기화되지만 총 작업 시간은 그대로 남습니다.

## 알아두면 좋은 것

- 창을 닫아도 시간은 흐릅니다
- 코드를 수정해도(재컴파일) 기록이 유지됩니다
- 에디터를 끄면 초기화됩니다
- 게임 빌드에는 안 들어갑니다

## 설정

```c#
// C6Timer.cs
const bool kTestMode = true;  // false로 바꾸면 실제 15분 간격
```
